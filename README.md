# Port Scanner (Python)

A multithreaded TCP Port Scanner developed in Python for network reconnaissance and security assessment.

## Features

- Scans ports 1–1023
- Detects open TCP ports
- Multi-threaded scanning for faster performance
- Basic banner grabbing
- Saves results to a text file

## Tools Used

- Python 3
- Socket Programming
- Threading
- Kali Linux

## Installation

Clone the repository:

git clone <repository-url>

## Run

python3 port_scanner.py

## Output

- Displays open ports
- Attempts banner grabbing
- Saves results in results.txt
